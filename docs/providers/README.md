# 官方预设与验证边界

核验时间：2026-10-06。只读取公开官方文档，没有登录或使用真实 Key。预设中的模型字符串为占位符；AI 必须按当前账号权限和官方来源选择。

| 预设     | 代表能力                        | 公开核验                                                                        |
| -------- | ------------------------------- | ------------------------------------------------------------------------------- |
| DS       | POST Chat、GET Models           | DeepSeek 首次调用页确认 Base URL / chat 路径；鉴权页确认 HTTP Bearer            |
| ARK Chat | POST Chat                       | 本轮直接 HTTP 读取到正文和 `/api/v3/chat/completions`                           |
| ARK 图片 | POST 图片生成                   | 官方目录入口确认，详情抓取为页面壳；具体样例字段需按当前官方页再核对            |
| ARK 视频 | 创建任务、查询/删除任务路径配置 | 前次同日官方正文确认创建 endpoint 和异步形态；本轮直接 URL 为页面壳，保留该差异 |
| TTS      | Qwen-TTS HTTP/SSE               | 本轮读取到百炼官方正文、请求路径、原生 input 与 SSE Header                      |

各预设文档列出官方来源，原始调查保留在 [research](../research/README.md)。这些是标注日期的公开资料核验；使用时仍应核对当前文档及账户可用范围。官方 HTTP 200 不代表正文、参数或业务能力已确认。

图片和视频样例仅是代表原生调用形态，不保证任意当前模型支持所有字段。方舟 Key 与豆包消费端账号、豆包语音产品不能混用。豆包语音官方文档入口已在研究中列出，实时双向语音和产品特定鉴权尚未实现。

所有真实平台仍需要用户通过 UI 配置凭据，实际厂商成功率、模型权限、计费、地区和当前媒体结果下载都未验证。更新按钮不自动跟随重定向；抓取失败保持旧文档，可手动导入厂商提供的 Markdown。
