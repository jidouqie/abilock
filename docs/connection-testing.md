# 连接测试

管理页的“测试连接”只使用已保存的地址、身份、范围和版本。草稿先保存，测试请求不携带新地址或凭据。状态“已配置”仍只表示本地字段齐全。结果是本次探测的证据，不是持续健康监控。

## 验证范围

| 类型 | 最小测试 | 结论与费用边界 |
|---|---|---|
| HTTP API（只读适配） | 已核验官方账户或模型目录查询 | 只验证该只读接口的鉴权，不调用生成模型；模型、生成内容及生成费用均无 |
| 豆包 / 火山方舟 | 用户选择已核验 Mini / Lite 模型并确认后，一次 Chat Completions | 固定短输入、最多 16 输出 tokens、关闭深度思考；可能计费，通过只代表所选模型本次成功 |
| SSH | 保存的主机指纹校验、登录握手、退出 | 指纹和登录通过；不打开命令、PTY、文件或转发通道 |
| PostgreSQL / MySQL | 建立会话，`SELECT 1 AS abilock_probe` | 常量查询通过，不读取业务表；免密服务器不能据此证明密码有效 |
| Redis | 建立会话，`PING` | 服务响应通过，不读取或修改业务键 |
| Git HTTPS | 固定仓库 Git 引用通告 | 验证 Git 协议响应；公开仓库不能证明凭据有效，不创建工作区 |
| Git SSH | 固定主机指纹及登录握手 | 不运行远端命令，不验证仓库读写权限 |
| S3 / OSS / R2 | 保存桶及前缀内一次 `ListObjectsV2`，最多 1 项 | 元数据响应通过；可能计一次 LIST 请求费，界面单独确认；不下载对象、不继续分页 |
| AWS | 已允许的 STS `GetCallerIdentity` | 官方端点验证签名身份；自定义 STS 端点仅表示兼容服务响应，不保证 AWS 凭据有效 |
| Docker Engine | 固定版本前缀下 `GET /version` | 版本响应通过；公开接口不能证明身份或容器管理权限 |
| OCI Registry | `GET /v2/`，校验协议版本 | 服务响应通过；不证明镜像仓库访问权限 |
| Kubernetes | 固定命名空间中一页已允许的非秘密资源，最多 1 项 | 不读 Secret、不扩大资源范围、不跟随分页；通过不代表其他资源权限 |

API 官方适配与未适配原因见[官方依据](research/connection-test-providers.md)。目前覆盖 OpenAI、OpenRouter、DeepSeek 根地址、Anthropic、Gemini、SiliconFlow 和原生 DashScope 的指定地址与鉴权方式。OpenRouter 使用当前 Key 的只读 `/api/v1/key` 接口，不调用模型；API 连接可以先留空密钥保存，未配置凭据时不能测试或调用。兼容网关、未知地址或需要真实生成才能确认的服务不会自动消费；须先明确提供商、模型、测试内容和费用上限。本轮没有真实供应商或计费验收。

豆包支持已保存的北京地域 `https://ark.cn-beijing.volces.com/api/v3` 与 Bearer API Key。点击测试首先显示选择与费用说明，不发送服务商请求；选择官方核验的 `doubao-seed-2-0-mini-260428` 或 `doubao-seed-2-0-lite-260428`，再确认才执行一次 `POST /api/v3/chat/completions`。固定输入 `Reply OK.`、`max_completion_tokens: 16`、`thinking.type: disabled`、`stream: false`、`service_tier: default`。不自动替换未开通模型，也不猜专属接入点 ID。管理模型清单需不同的 AK/SK；公开列表不能证明当前 Key 有效。官方分词接口虽支持 API Key，但其费用和这两个模型的支持范围未取得足够证据，未冒充免费通用鉴权。详见[豆包依据与当前单价](research/doubao-connection-test.md)。

界面显示模型单价与核对日期；请求次数和 token 限制不是人民币账单硬上限。服务商已受理时，即使取消或超时也可能计费。未填密钥、鉴权失败、模型未开通或无权限、余额/额度、限流、网络和协议错误分别显示，不把 HTTP 200 当成功；生成成功需响应模型与所选模型一致、结构与用量有效。

不能满足原有资源范围的测试返回“尚未验证”，不会改写执行范围。S3 的费用确认限定一次请求，不等于确定货币价格；实际价格由提供商和地区决定。其他测试也不承诺第三方未来价格不变。

## 操作与保护

- 测试 30 秒超时，界面留有取消收尾时间；不自动重试。用户可取消，关闭编辑器、导航、修改草稿或退出也会取消，并忽略迟到结果。
- 同一连接在管理服务内只允许一个测试；旧 SSH 测试入口也共用这个限制。取消后不把已经发出的请求说成未受理。
- 服务端解析请求后重新读取保存状态，检查 revision，完成时再次比较完整记录；轮换、停用、删除或重新创建的旧结果不显示为成功。网络等待不持有 Store 写锁。
- 使用既有固定目标、DNS、TLS、身份及资源检查。HTTP 不跟随重定向；请求路径由程序选择，不能由手册或测试参数覆盖。
- 鉴权、权限、余额、限流、网络、TLS、协议、超时及取消使用固定分类。上游正文、账号身份和密钥不进入结果或错误文本。
- 测试入口仅属于管理角色，不增加公开 CLI、秘密读取或鉴权写入入口。当前页面与服务端需同时更新，才能使用新行为。

本轮自动化均使用合成凭据、临时存储、mock 或本机临时协议服务。真实 SSH、商家权限、余额、收费、桌面安装与 Windows 安装升级均未实测。
